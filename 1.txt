step by step process to push files to remote repository using git:
git add . 
git commit -m "initial commit"
git branch -m main     -- to change the branch from master to main
git remote add origin <your-repo-url>  -- to add the remote repository 
git push -u origin main  -- to push the changes to the remote repository for the first time
git push  -- to push the changes to the remote repository after the first time

first put files on staging part of git using "git add"
then commit those files locally using the "git commit -m "your commit message" 
then you can push those files to the remote repository using "git push"


the three stages of git are:
1. Working Directory: This is where you make changes to your files. Any modifications you make are done in this area. You can see the changes you have made to your files here.
2. Staging Area: This is where you prepare your changes before committing them. You can add files to the staging area using "git add <file-name>" or "git add ." to add all changes. This allows you to review and organize your changes before committing them.
3. Repository: This is where your committed changes are stored. Once you commit your changes using "git commit -m 'your commit message'", they are saved in the repository. You can then push these changes to a remote repository using "git push".


other git commands which are useful:
git status  -- to check the status of your files in the working directory and staging area
git log  -- to view the commit history of your repository
git diff -- to see the differences between your working directory and the staging area or between commits
git diff --staged -- to see the differences between the staging area and the last commit
git restore <file-name> -- to discard changes in the working directory and restore the file to the last committed state
git reset <file-name> -- to unstage a file from the staging area and move it back to the working directory
git rm <file-name> -- to remove a file from the working directory and staging area
git rm --cached <file-name> -f -- to remove a file from the staging area but keep it in the working directory



** branching **
what is a branch in git?
A branch in Git is a separate line of development that allows you to work on different features or bug fixes independently from the main codebase. Each branch can have its own commits, and you can switch between branches to work on different tasks without affecting the main branch. This enables collaborative development and helps manage changes in a more organized way.

git branch <branch-name> -- to create a new branch
git checkout <branch-name> -- to switch to a different branch 
git checkout -b <branch-name> -- to create a new branch and switch to it in one command
git pull -- to fetch and merge changes from the remote repository into your current branch

step by step process to create a new branch and push it to remote repository:
1. Create a new branch using the command: git branch <branch-name>
2. Switch to the new branch using the command: git checkout <branch-name>
3. Make changes to your files in the working directory.
4. Add the changes to the staging area using the command: git add .
5. Commit the changes using the command: git commit -m "your commit message"
6. Push the changes to the remote repository using the command: git push -u origin <branch-name>




*** Branching & Merging ***
what is branching and merging in git?
Branching in Git allows you to create separate lines of development, enabling you to work on different features or bug fixes independently. Merging is the process of integrating changes from one branch into another, typically from a feature branch back into the main branch. This allows for collaborative development and helps manage changes in a more organized way.

so multiple users can share solution to a particullar problem by creating their own branches and then merging them into the main branch after review and testing. This way, the main branch remains stable while new features or fixes are developed in isolation.


processs to create new branch and merging to main branch:
1. Create a new branch using the command: git branch <branch-name>  
2. Switch to the new branch using the command: git checkout <branch-name>
3. Make changes to your files in the working directory.
4. Add the changes to the staging area using the command: git add .
5. Commit the changes using the command: git commit -m "your commit message"
6. Switch back to the main branch using the command: git checkout main
7. Merge the changes from the new branch into the main branch using the command: git merge <branch-name>
